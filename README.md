# Geradora de APAC Externa — código oficial

Código oficial da **Geradora de APAC Externa** (Google Planilhas + Apps Script).
Cada unidade usa a própria cópia da planilha; o botão
**📋 APAC ▸ 🔧 Ferramentas ▸ 🔄 Atualizar sistema** baixa daqui a versão mais recente.

- `versao.json` — versão oficial, novidades e lista de arquivos.
- `codigo/` — arquivos do Apps Script.

Este repositório **não contém** chaves, códigos de acesso nem dados de pacientes.
